# Sheepy Business

Sheepy Business is an Unity game project centred on running a sheep farm. It includes the game scenes, prefabs, animations, audio, fonts, and supporting C# scripts used by the project.

## Play

Play the published version here: [Sheepy Business](https://ba6ta-ti.itch.io/sheepy-business).

## Project contents

| Path | Purpose |
| --- | --- |
| `Scenes/` | Main menu, gameplay, options, and how-to-play scenes. |
| `Scripts/` | C# behaviours for audio, UI layout, and animation handling. |
| `Prefabs/` | Reusable game objects, including the player, sheep, grass, and audio components. |
| `Animations/` | UI and feedback animation controllers and clips. |
| `Audio/` | Music and sound effects. |
| `Fonts/` | Font files and TextMesh Pro font assets. |

## Requirements

- [Unity](https://unity.com/download) 2021.3.16f1 or a compatible Unity 2021 LTS release
- A C# editor, such as Visual Studio

## Open the project

1. Clone or download this repository.
2. Open the project in Unity Hub with Unity 2021.3.16f1 or a compatible Unity 2021 LTS release.
3. In the Unity Editor, open `Scenes/MainMenu.unity` to start from the main menu, or `Scenes/Game.unity` to work directly on the gameplay scene.
4. Press Play in the editor to test changes.

> The included `Assembly-CSharp.csproj` is generated by Unity. Let Unity regenerate it if your editor reports stale project references.
